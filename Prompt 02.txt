1. CONTEXTO DEL SISTEMA

TusFinanzas es una aplicación de finanzas personales que permite a cada usuario:
* Registrar sus datos de perfil y configurar una moneda principal mediante código ISO 4217.
* Registrar fuentes de ingreso y sus respectivas periodicidades.
* Registrar los ingresos efectivamente recibidos y las deducciones aplicadas a cada ingreso.
* Calcular el ingreso neto recibido y consultar el total mensual, distinguiendo datos reales de estimaciones.
* Registrar, categorizar y consultar gastos obligatorios, necesarios variables y discrecionales.
* Controlar gastos fijos, variables, ocasionales, recurrentes, pagados, pendientes y vencidos.
* Registrar deudas, saldos pendientes y pagos asociados.
* Identificar patrones de gastos pequeños, frecuentes o repetitivos que podrían representar gastos hormiga.
* Consultar balances mensuales y estimaciones de capacidad de ahorro con fórmulas y datos de origen explicables.
* Mantener privados sus ingresos, gastos, deudas y análisis financieros.

La plataforma es una herramienta de registro, organización y análisis descriptivo. No debe presentarse como asesor financiero profesional ni emitir recomendaciones de inversión, tributarias o crediticias personalizadas.

2. ARQUITECTURA OBJETIVO

El sistema debe cumplir una arquitectura por capas estricta:

Frontend (React + TypeScript)
    -> API / Controllers (FastAPI)
        -> Service Layer (casos de uso y reglas de negocio financiero)
            -> Persistence Layer (SQLAlchemy 2.0 + PostgreSQL 18)

Cada capa debe:
* Tener responsabilidades claras y respetar Separation of Concerns (SoC).
* No invadir las responsabilidades de las demás capas.
* Cumplir el principio de responsabilidad única (SRP).
* Mantener dependencias controladas y evitar acoplamiento innecesario.
* Garantizar que los cálculos financieros no estén implementados directamente en componentes React ni en rutas HTTP.
* Mantener la lógica de negocio crítica en el backend; el frontend puede presentar resultados, pero no constituye la fuente de verdad de los cálculos.
